## Isi dan perilaku sumber

- Bookmark disimpan lokal dengan identitas surat/ayat, catatan, UUID dan timestamp.
- Snapshot runtime pada profil bersih menampilkan belum ada bookmark. Yang disimpan hanya kontrak data, bukan record pengguna.

## Batasan dan penggunaan

Tidak ada dataset publik bookmark yang bisa diambil. Jangan menafsirkan kosong sebagai kegagalan mengambil data server.

Semua file menggunakan envelope `schemaVersion`, `sourceSite`, `extractedAt`, `sources`, `notes`, `data`. Dataset ini arsip terpisah; belum diimpor ke SQLite atau dipakai UI MyAlQuran.
