## Isi dan perilaku sumber

- Delapan preset dzikir, target hitungan, dan fadhilah sumber.
- Lima teks cocok dengan doa lokal setelah normalisasi Arab: simpan existingRef, hapus salinan arabic/latin/translation. Tiga bacaan lainnya tetap lengkap.
- Hitungan/session pengguna adalah localStorage; tidak diambil dan tidak diganti data palsu.

## Batasan dan penggunaan

Fadhilah dan nisbah hadis disalin sebagai klaim sumber, bukan pengesahan validitas hadis.

Semua file menggunakan envelope `schemaVersion`, `sourceSite`, `extractedAt`, `sources`, `notes`, `data`. Dataset ini arsip terpisah; belum diimpor ke SQLite atau dipakai UI MyAlQuran.
