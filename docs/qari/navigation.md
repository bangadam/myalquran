## Isi dan perilaku sumber

- Alias route dan 13 entri navigasi sumber disimpan tanpa komponen ikon React.
- 13 route fitur plus home diperiksa dengan MCP REA. Halaman musiman Ramadan tidak diabaikan hanya karena tersembunyi dari menu.
- Korpus terbatas konten publik yang dikirim aplikasi dan endpoint yang ditemukan. Tidak mengakses admin, akun privat, atau endpoint hasil tebakan.

## Batasan dan penggunaan

Data runtime dinamis dibatasi snapshot terdokumentasi; bukan klaim seluruh kemungkinan respons layanan pihak ketiga.

Semua file menggunakan envelope `schemaVersion`, `sourceSite`, `extractedAt`, `sources`, `notes`, `data`. Dataset ini arsip terpisah; belum diimpor ke SQLite atau dipakai UI MyAlQuran.
